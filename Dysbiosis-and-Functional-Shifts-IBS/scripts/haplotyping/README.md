# Strain-level haplotyping

This directory is reserved for validated anvi'o and DESMAN commands and scripts supporting the strain-level haplotyping analysis.

The final reproducibility record should document:

- generation of SNV variability profiles with anvi'o;
- the 71 universal single-copy core-gene set;
- candidate haplotype numbers evaluated;
- DESMAN iterations and replicate runs;
- random seeds;
- posterior-deviance assessment;
- the criteria used to select the optimal haplotype number.

Historical plotting scripts or incomplete DESMAN examples should remain under `archive/` until their relationship to the final analysis is verified.
