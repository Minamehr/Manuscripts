# Legacy exploratory network analysis

This directory contains the original exploratory SparCC/FastSpar network-analysis
commands, including fixed correlation-threshold filtering, centrality analysis,
hub identification, fragmentation comparisons, and Cytoscape visualization.

These analyses are retained only for provenance and are not used to support the
final manuscript conclusions.

The final microbial association analysis accounts for unequal group sizes,
multiple testing, resampling uncertainty, prevalence filtering, correlation
threshold sensitivity, and correlation-estimator sensitivity. It did not provide
robust evidence of widespread microbial-network fragmentation or global network
reorganization in IBS.

The exact scripts used for the final analysis should be deposited separately in
the main analysis directory before the repository is cited in the submitted
manuscript.
